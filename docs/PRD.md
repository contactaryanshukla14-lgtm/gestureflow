# GestureFlow PRD

GestureFlow is a complete human-computer interaction project for gesture recognition that combines a web frontend, API backend, ML training pipeline, and packaged documentation. The system is designed to support webcam-based gesture commands such as open palm, fist, thumbs up, peace, OK, point left, point right, and stop.

## Scope
- Real-time webcam interface
- Backend inference and logging APIs
- Dataset capture and preprocessing scripts
- Training, evaluation, and export stubs
- Architecture and technical stack READMEs

## Recommended Next Implementation
Replace the demo inference service with a MediaPipe custom gesture recognizer or landmark-based classifier and populate the dataset folders using the provided capture utility.
